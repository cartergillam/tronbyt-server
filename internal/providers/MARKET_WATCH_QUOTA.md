# Market Watch Basic-plan budget

Quote identity is credential owner scope + canonical listing ID + expected currency. Legacy AUTO or exchange-qualified symbols retain separate identities because an unspecified venue must not silently substitute an explicit listing. Name, order, Focus/Ticker, colors, device and installation do not enter quote keys. Overlapping watchlists reuse individual listing snapshots, and adapter serialization coalesces simultaneous refresh decisions. Snapshots use the existing in-process Cache; restarting the server loses caches and local usage accounting.

OPEN target freshness: 5 minutes; watchlists above eight listings use 6 minutes to preserve daily headroom. CLOSED/unknown freshness: 60 minutes. Each listing selects its own TTL. Known XNAS (including XNGS/XNMS/XNCM segments), XNYS/ARCX/XTSE closing snapshots timestamped at or after the latest weekday close are retained until the next weekday 09:30 America/New_York opening. Morning TTLs stop at that opening. This conservative weekday bound is not an exchange holiday calendar; other listings retain provider state and hourly refresh. LKG survives an additional 72 hours beyond freshness and is marked STALE on refresh failure/defer, without mutating cached data.

Uncached symbols with identical quote parameters use comma-separated `/quote` batches of at most five symbols; a ten-symbol cold watchlist fetches its first group and defers the other group until minute capacity returns. Different MIC/exchange filters use separate batches to preserve exact venue selection. Each attempted symbol costs one quote credit. Each response entry is independently validated (including symbol/MIC/currency); good quotes survive errors in peers. Missing/malformed entries are BAD RESPONSE. A failed symbol uses LKG when available, otherwise its sanitized error. Non-retryable errors are remembered 24 hours (invalid key: 15 minutes); retryable failures 30 seconds (local credit deferral: 60 seconds); actual provider rate limits back off 15 minutes across watchlists. Successful credential validation clears cache/failure/backoff state.

Ordinary response headers capture `api-credits-left` and `api-credits-used`; invalid/negative/overflowing values are ignored. Observations are private adapter state keyed by a secret hash, never logged or rendered. Their sum is recorded as an observed limit, not daily availability. Local reservations enforce at most 8 credits in a conservative 60-second window, lowering headroom with provider headers; insufficient batch headroom defers the full batch and serves LKG. Search/logo/validation also reserve credits. No `/api_usage` polling is added. Local daily counters cap quotes at 700 and all managed operations at 750 per UTC day. These are protective process-local ceilings, not precise provider daily remaining credits: restarts and outside consumers are not accounted for. Provider daily 429 responses still invoke backoff. Diagnostics expose sanitized aggregate requests, quote credits, refreshed symbols, batch size, cache hits/misses and defers; no per-render production logging.

Five symbols × (390 session minutes / 5-minute freshness) ≈ **390 quote credits** per ordinary full US session. Ten symbols blindly refreshed at five minutes would cost **780**, leaving inadequate headroom. Ten-listing watchlists instead use a six-minute TTL per listing: 10 × (390 / 6) ≈ **650 quote credits**, with the two five-symbol groups naturally staggered by at least a minute. Confirmed closing snapshots add a small number of credits and avoid overnight/weekend polling. Initial snapshots, failures, holidays and timing vary; these numbers are estimates. The local quote cap stays 700 and all managed operations cap at 750 to leave room for searches, validation and outside consumers. These counters reset at midnight UTC and are not authoritative across restarts/external use. Multiple disjoint watchlists sharing a key may reach the soft cap and receive STALE data. Five/six-minute freshness is a target, never permission to consume final credits.

Search results: 24-hour freshness with seven-day LKG, normalized query and credential scope; errors aren't stored as successful results. Remote logo metadata/images: 30-day freshness with 30/90-day LKG. Permanent unavailable/unsafe logo results: 24-hour negative cache. AAPL and MSFT US NASDAQ/USD listings (including XNGS/XNMS/XNCM segments) use embedded approved transparent SVGs, resolved before remote caches, normalized once per versioned logo-cache key and cached for a year, without provider requests. Failed acquisition retains ticker-letter fallback. Logo keys include a normalization revision and curated asset fingerprint. That fingerprint and device assignment enter Market Watch render context identity. Cached quote snapshots have a separate read-only revision so new data updates rendered output without any fingerprint operation triggering a provider request. The Apple source fixture is an opaque black-on-white JPEG; the former Pixlet logo box also filled the canvas pale gray. Microsoft's former pale background made transparent gaps/borders visible. Explicit overrides eliminate dependence on unsuitable provider backgrounds without stripping white from arbitrary logos or modifying sports normalization.

All quota tests use mock HTTP transports. `TestMarketQuotaSharedListingBatchAndConcurrentRenders`, server injection cache tests, and fixture animation tests demonstrate shared snapshots and frame-independent provider usage. `TestMarketQuotaCreditHeadersSafeAndLocalDailyBound` checks the 650-credit session calculation.


## Credentials and device assignment

The existing AES-GCM credential store already supported multiple IDs per provider/owner. Labels and creation/update metadata make that visible; IDs remain stable and globally unique for legacy compatibility. iOS creates unique IDs automatically and displays labels. Device `market_credential_id` stores the owner-owned logical credential, never ciphertext/plaintext. Owner-only PUT `/v0/devices/{id}/market-credential` assigns/clears it; GET returns the ID/label to the owner and only `configured` to authorized members. Credential lists include assigned device IDs for owner UI. Members cannot create, replace, disable, delete, validate or assign keys and cannot change installation overrides. Member stock search ignores arbitrary client credential selection and uses the device assignment.

Resolution: nonempty installation override other than legacy schema default `market-primary`/`__device__` → device assignment → legacy owner `market-primary` → SETUP REQUIRED if absent/disabled/wrong provider. A saved `market-primary` is treated as automatic when an assignment exists. Owner-configured legacy nondefault installation overrides remain supported. Authorization derives owner scope from the authorized device, never a client-provided owner ID. Cache scopes include owner + credential ID + encrypted-key version; replacement invalidates only that credential's quotes/search/failure state, and disabled keys cannot serve fresh cached quotes. Same assigned credential + listing shares snapshots across devices. Different credentials isolate quote/search/backoff state and different raw keys isolate credit reservations/counters via private SHA-256 identities.

## Canadian symbols

`PLZ.UN` is a valid Twelve Data TSX/XTSE listing: https://twelvedata.com/markets/108274/stock/tsx/plz.un . Dots were already preserved by server and iOS validation, canonical IDs and URL encoding. The error classifier formerly mapped every provider 400/404 to BAD SYMBOL even if its message identified a plan/subscription restriction. Entitlement messages now take precedence over those generic codes. A valid exact Canadian selection receiving a plan error becomes PLAN REQUIRED; a truly invalid-symbol response remains BAD SYMBOL. Search `access.plan` is preserved and iOS displays a nonblocking upgrade notice. Public discovery is not proof that an individual API key can quote a listing: https://support.twelvedata.com/en/articles/5332349-commercial-and-personal-usage . No historical provider response or physical-device runtime trace was available in these repositories, so the precise original account entitlement and exact stale physical cache layer cannot be asserted from tests alone.

The physical Apple issue has two confirmed code-level causes: the override was evaluated inside a cache miss callback, so cached remote artwork won, and the approved-ID map excluded NASDAQ market-segment MICs. Overrides now win before all remote/legacy caches, accepted NASDAQ MICs retain exact listing identity, and asset/normalization fingerprints invalidate only Market Watch logo/render output. Microsoft uses identical precedence/versioning without changing its approved asset.

CLOSED messages are absent from both display modes. Closure does not mark a valid closing snapshot stale. Actionable provider errors, explicit EOD/delayed indicators and genuine STALE conditions remain. Ten-symbol ticker uses sequential bounded current/next-card strips: 960 one-pixel frames × 55 ms = 52.8 seconds, below the 60-second Market Watch encode allowance and 2,000-frame Pixlet ceiling. This also works with the installed older Pixlet's Marquee spatial cap. No animation/frame performs provider I/O.
