# Market Watch Basic-plan budget

Quote identity is credential owner scope + canonical listing ID + expected currency. Legacy AUTO or exchange-qualified symbols retain separate identities because an unspecified venue must not silently substitute an explicit listing. Name, order, Focus/Ticker, colors, device and installation do not enter quote keys. Overlapping watchlists reuse individual listing snapshots, and adapter serialization coalesces simultaneous refresh decisions. Snapshots use the existing in-process Cache; restarting the server loses caches and local usage accounting.

OPEN freshness: 3 minutes. CLOSED/unknown freshness: 60 minutes. Each listing selects its own TTL. Known XNAS/XNYS/ARCX/XTSE closing snapshots timestamped at or after the latest weekday close are retained until the next weekday 09:30 America/New_York opening. Morning TTLs stop at that opening. This conservative weekday bound is not an exchange holiday calendar; other listings retain provider state and hourly refresh. LKG survives an additional 72 hours beyond freshness and is marked STALE on refresh failure/defer, without mutating cached data.

Uncached symbols with identical quote parameters use one comma-separated `/quote` batch; different MIC/exchange filters use separate batches to preserve exact venue selection. Each attempted symbol costs one quote credit. Each response entry is independently validated (including symbol/MIC/currency); good quotes survive errors in peers. Missing/malformed entries are BAD RESPONSE. A failed symbol uses LKG when available, otherwise its sanitized error. Non-retryable errors are remembered 24 hours (invalid key: 15 minutes); retryable failures 30 seconds; actual provider rate limits back off 15 minutes across watchlists. Successful credential validation clears cache/failure/backoff state.

Ordinary response headers capture `api-credits-left` and `api-credits-used`; invalid/negative/overflowing values are ignored. Observations are private adapter state keyed by a secret hash, never logged or rendered. Their sum is recorded as an observed limit, not daily availability. Local reservations enforce at most 8 credits in a conservative 60-second window, lowering headroom with provider headers; insufficient batch headroom defers the full batch and serves LKG. Search/logo/validation also reserve credits. No `/api_usage` polling is added. Local daily counters cap quotes at 700 and all managed operations at 750 per UTC day. These are protective process-local ceilings, not precise provider daily remaining credits: restarts and outside consumers are not accounted for. Provider daily 429 responses still invoke backoff. Diagnostics expose sanitized aggregate requests, quote credits, refreshed symbols, batch size, cache hits/misses and defers; no per-render production logging.

Five symbols × (390 session minutes / 3-minute freshness) ≈ **650 quote credits** per ordinary full US session. A confirmed closing snapshot adds approximately five credits and avoids overnight/weekend polling. Initial/pre-open snapshots and timing variation can add a few cycles. Without a confirmed close, hourly closed checks add usage, bounded locally by the 700 quote-credit ceiling. Search, validation, retries and manual operations use remaining headroom; do not treat 650 as an absolute daily guarantee or batching as a credit discount. Multiple disjoint watchlists share the same credential budget and may receive STALE data at the ceiling.

Search results: 24-hour freshness with seven-day LKG, normalized query and credential scope; errors aren't stored as successful results. Remote logo metadata/images: 30-day freshness with 30/90-day LKG. Permanent unavailable/unsafe logo results: 24-hour negative cache. AAPL/XNAS/USD and MSFT/XNAS/USD use embedded approved transparent SVGs, normalized once per logo-cache key and cached for a year, without provider requests. Failed acquisition retains ticker-letter fallback. The Apple source fixture is an opaque black-on-white JPEG; the former Pixlet logo box also filled the canvas pale gray. Microsoft's former pale background made transparent gaps/borders visible. Explicit overrides eliminate dependence on unsuitable provider backgrounds without stripping white from arbitrary logos or modifying sports normalization.

All quota tests use mock HTTP transports. `TestMarketQuotaSharedListingBatchAndConcurrentRenders`, server injection cache tests, and fixture animation tests demonstrate shared snapshots and frame-independent provider usage. `TestMarketQuotaCreditHeadersSafeAndLocalDailyBound` checks the 650-credit session calculation.
